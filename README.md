# 2017-Animation-using-C-and-OpenGL-for-graphics

Jamination is an animation project using C++ and OpenGL project developed using Visual Studio 2017.

## Technologies
- C++
- OpenGL
- FreeGLUT
- GLEW
- Visual Studio 2017 (v141 toolset)

## Building
The project was originally developed and tested using Visual Studio 2017.
Open `Jamination.sln` in Visual Studio to build the project.
Windows 10 packages may be neccesary to install if on a different version of Windows.
